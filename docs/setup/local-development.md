# Local Development Guide

## Prerequisites

- **Node.js**: `v20+`
- **pnpm**: `v8+`
- **Docker Desktop**: Running locally

## Step-by-Step Setup

### 1. Repository Setup

```bash
git clone [https://github.com/mfvicky/video-streaming-platform.git](https://github.com/mfvicky/video-streaming-platform.git)
cd video-streaming-platform
pnpm install
pnpm run prepare # Setup Husky git hooks
```
